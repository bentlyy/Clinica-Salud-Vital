# Analytics

## Endpoints (Admin)
- `GET /analytics/dashboard` — Dashboard stats
- `GET /analytics/appointments` — Estadísticas de citas
- `GET /analytics/revenue` — Estadísticas de ingresos

## Features
- Dashboard con métricas clave
- Integración con [[Modules/ML|ML]] para predicciones
- Stats de ocupación, ingresos, tendencias
- Frontend con Recharts
