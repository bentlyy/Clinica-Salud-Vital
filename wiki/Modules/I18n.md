# i18n (Internacionalización)

Gestión de traducciones multi-idioma para backend y frontend.

## Endpoint
- `GET /i18n/translations` — Todas las traducciones

## Features
- **421+ claves** traducidas en 4 idiomas
- Locales: `es`, `en`, `pt`, `fr`
- Backend: `i18n.service.ts` con `t(key)` y `tAll(key)`
- Frontend: `useI18n` hook + `I18nContext` + `I18nProvider`
- Fallback automático a español si falta clave
- Locale reactivo vía custom event (`locale:changed`)
- Cache en localStorage con fetch a API
