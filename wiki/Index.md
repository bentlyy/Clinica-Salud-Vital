# 🏥 Clinic Backend — Wiki del Proyecto

Sistema de gestión clínica full-stack (Node.js + Express 5 + React + Vite + PostgreSQL 15).
Desplegado en Render. ML con TensorFlow.js.

## Stack

| Capa | Tecnología |
|------|-----------|
| Backend | Node.js + Express 5 + TypeScript |
| Frontend | React 19 + Vite 6 + MUI |
| DB | PostgreSQL 15 |
| ML | TensorFlow.js |
| Email | SendGrid / Gmail SMTP |
| SMS | Twilio (log mode) |
| Auth | JWT + Refresh Tokens + 2FA/TOTP |
| Payment | Stripe (stub mode) |
